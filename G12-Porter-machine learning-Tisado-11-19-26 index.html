How to Use This Tool

Follow these four simple steps to accurately classify any waste item using the trained AI model.

01

Choose Input Method

Select either Live Webcam for real-time scanning or Upload Image to test a photo from your device.

02

Allow Permissions / Select File

Grant browser camera access if using the webcam, or pick a clear, well-lit photo of the waste item.

03

Position the Waste Item

Hold the item steady in front of the camera (ideally against a plain background) or ensure the uploaded image is centered.

04

View AI Classification

Read the real-time confidence bars to see which waste category the model predicts, then follow proper disposal practices.
